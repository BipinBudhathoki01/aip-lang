# Community Code of Conduct

Be respectful, constructive, and patient with contributors of all experience levels. Critique code and ideas rather than people. Welcome different backgrounds and perspectives.

Harassment, threats, discriminatory language, sexual harassment, publication of private information, and deliberate disruption are not acceptable in project spaces.

Maintainers may edit or remove harmful content, close disruptive discussions, and restrict participation when necessary. Responses should be proportionate and consider context.

Report conduct concerns privately to the maintainer using the contact options on https://github.com/BipinBudhathoki01. If no private contact is listed, use GitHub's platform reporting tools; do not post another person's private information in an issue.

This policy applies to repository issues, pull requests, discussions, and other spaces maintained by this project.
